# 📊 Excel Sales Analysis – Studio & Carrier Wise Report

## 📌 Project Overview
This project analyzes movie order data using Microsoft Excel.

The objective of this project is to:

- Split raw order data based on business requirement
- Generate Studio-wise sheets
- Create Carrier & Title wise summary
- Calculate Total Quantity Sold
- Calculate Total Revenue
- Present structured summary for reporting

---

## 🛠 Tools Used
- Microsoft Excel
- Pivot Tables
- Aggregation (SUM of Qty, SUM of Total)
- Sheet Splitting by Studio

---

## 📊 Key Analysis

✔ Carrier & Title Wise Total Quantity  
✔ Carrier & Title Wise Total Revenue  
✔ Separate Sheet for Each Studio  
✔ Structured Reporting Format  

---

## 🎯 Business Requirement

Generate:

> Carrier & Title wise Total Quantity Sold and Total Revenue for each Studio on different sheets.

This project demonstrates practical Excel data transformation and reporting skills.
