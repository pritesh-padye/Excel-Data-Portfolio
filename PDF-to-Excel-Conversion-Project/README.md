# 📄 PDF to Excel Conversion Project

## 📌 Project Overview
This project demonstrates the complete process of converting unstructured investor data from PDF into a structured, clean, and analysis-ready Excel report.

The goal of this project is to showcase professional data cleaning, transformation, and reporting skills using Microsoft Excel.

---

## 🎯 Project Objectives
✔ Extract data from PDF  
✔ Clean and structure raw extracted data  
✔ Apply Excel formatting and formulas  
✔ Generate analytical pivot reports  
✔ Convert unstructured data into business insights  

---

## 📂 Project Files

### 📄 Investor_Data.pdf
Original raw investor dataset in PDF format.

### 📊 Raw_Data.xlsx
Data extracted from PDF without cleaning.  
Contains merged and unstructured values.

### 🧹 Clean_and_Report.xlsx
Contains two sheets:

#### 🔹 Clean_Data Sheet
- Split combined columns
- Standardized text formatting
- Currency formatting applied
- Removed inconsistencies
- Structured tabular dataset

#### 🔹 Report Sheet
Created Pivot Table based report including:
- City-wise Investment Summary
- Average Annual Return %
- Business ready summarized insights
