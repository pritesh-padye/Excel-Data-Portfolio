# 📂 Projects Included

## 📦 Project 1 – Inventory Closing Stock Highlighting

### 🔹 Objective
To visually categorize stock levels using rule-based conditional formatting.

### 🔹 Key Features
- 🔴 Closing Stock < 500 → Low Stock
- 🟡 500–800 → Medium Stock
- 🟢 > 800 → High Stock
- Currency formatting applied
- Structured tabular format
- Clean and organized dataset

### 💼 Business Value
Helps businesses monitor inventory levels instantly.

---

## 📦 Project 2 – Insurance Data Conditional Formatting Analysis

### 🔹 Objective
To analyze insurance operational data using advanced conditional formatting techniques.

### 🔹 Key Features
- Up-Sell Amount color categorization:
  - 🔴 <= 150
  - 🟡 151–300
  - 🟢 > 300
- Heat Map applied on Satisfaction Ratio column
- Entire row highlighted where Resolved status = "No"
- Clean structured data table
- Business-ready formatting

### 💼 Business Value
Helps management identify:
- Low up-sell performance
- Customer satisfaction trends
- Unresolved cases quickly
