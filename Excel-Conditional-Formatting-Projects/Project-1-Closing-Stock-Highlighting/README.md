# 📊 Closing Stock Conditional Formatting Project

## 📌 Project Overview
This project demonstrates advanced Custom Conditional Formatting, Data Cleaning, and Professional Tabular Formatting in Microsoft Excel.

The purpose of this project is to visually highlight higher and lower closing stock levels to make stock analysis faster and easier for business decision-making.

---

## 🎯 Project Objectives
- Identify low, medium, and high closing stock instantly
- Improve data readability using tabular formatting
- Apply professional currency formatting
- Convert raw stock data into a clean and structured format

---

## 🛠 Tools & Features Used
- Microsoft Excel
- Custom Conditional Formatting
- Currency Formatting
- Table Formatting
- Data Cleaning Techniques

---

## 📊 Conditional Formatting Rules Applied

The Closing Stock column uses custom conditional formatting rules:

| Closing Stock Range | Highlight Color | Purpose |
|---------------------|-------------|------------|
| Less than 500 | 🔴 Red | Low Stock Indicator |
| 500 to 800 | 🟡 Yellow | Medium Stock Indicator |
| Greater than 800 | 🟢 Green | High Stock Indicator |

These rules help users quickly identify stock availability without manual checking.
