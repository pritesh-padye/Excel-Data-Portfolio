# 📊 Insurance Data Conditional Formatting Project

## 📌 Project Overview
This project focuses on analyzing insurance operational data using advanced Conditional Formatting techniques in Microsoft Excel.

The goal is to improve data visibility, highlight important business insights, and make performance tracking easier.

---

## 🎯 Objectives
- Identify low and high Up-Sell performance
- Visualize customer satisfaction using heat maps
- Highlight unresolved cases automatically
- Improve report readability

---

## 📊 Conditional Formatting Rules Applied

### 🔹 Task 1 – Up-Sell Amount Categorization
- <= 150 → 🔴 Red
- 151 – 300 → 🟡 Yellow
- > 300 → 🟢 Green

### 🔹 Task 2 – Heat Map
Applied color scale heat map on Satisfaction Ratio column to visually represent performance levels.

### 🔹 Task 3 – Row Highlighting
Entire row highlighted when Resolved status = "No".
