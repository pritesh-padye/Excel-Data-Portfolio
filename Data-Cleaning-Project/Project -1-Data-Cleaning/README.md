# 📊 Excel Data Cleaning Project

## 📌 Project Overview

This project focuses on cleaning and organizing structured sales data in Microsoft Excel.

The dataset contained transactional details such as Order Date, Customer Information, Product Details, Sales, Quantity, and Discount.  
The objective was to improve data accuracy, remove inconsistencies, and prepare the dataset for reliable analysis.

## 🔧 Tasks Performed

### ✅ Task #1 – Data Cleaning (Error Removal)

- Identified and removed errors from:
  - Sales column  
  - Quantity column  
  - Discount column  
- Ensured numerical consistency.
- Corrected invalid or inconsistent values.
- Improved data accuracy for analysis.

---

### ✅ Task #2 – Duplicate Removal

- Checked entire dataset for duplicate records.
- Removed duplicate entries using Excel’s duplicate handling tools.
- Ensured unique transaction records.
- Prevented data overcounting and reporting errors.

---

### ✅ Task #3 – Data Organization

- Sorted dataset based on **Weekday** column.
- Structured the data for weekday-based analysis.
- Improved readability and reporting structure.
